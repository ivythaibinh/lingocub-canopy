# Lingo Cub · Canopy — Thành phố thám hiểm

Web tự học Anh – Trung cho bé 7–10 tuổi (khóa Canopy, 12 unit).

- `index.html` — bản đồ thành phố: 12 trạm, công trình xây dần theo bài đã học, hồ sơ nhà thám hiểm (avatar, thống kê).
- `u1to4/` (Unit 1–4), `u5/` … `u12/` — trang từng trạm.
- `cdata.js` — tên unit, tên bài, hình công trình, avatar; `demoOpenAll:false` = trạm mở lần lượt (đặt `true` để mở hết khi xem thử).
- `lc.js`, `lc.css` — lớp giao diện dùng chung cho các trạm.

Tiến độ lưu trong trình duyệt của máy (localStorage). Mã giáo viên trên bản đồ: 2468.
